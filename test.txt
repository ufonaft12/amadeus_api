Это отличный вопрос! В PySpark (и в Big Data вообще) трансформации делятся на два типа: узкие (когда данные не перемещаются между узлами сервера) и широкие (когда данные перемешиваются, например, при группировке).
Давай разберем "джентльменский набор" дата-инженера. Я подготовил для тебя шпаргалку самых популярных методов.
1. Основные методы трансформации (как в SQL)
Если ты знаешь SQL, тебе будет легко провести аналогию. В PySpark почти для каждого оператора SQL есть свой метод.
| Операция SQL | Метод PySpark | Описание |
|---|---|---|
| SELECT name, code | .select("name", "code") | Выбор колонок |
| WHERE type = 'AIRPORT' | .filter(F.col("type") == "AIRPORT") | Фильтрация строк |
| AS alias_name | .alias("new_name") | Переименование колонки внутри select |
| DISTINCT | .dropDuplicates() | Удаление полных дубликатов |
| LIMIT 10 | .limit(10) | Ограничение количества строк |
| ORDER BY name | .orderBy("name") | Сортировка (по возрастанию/убыванию) |
2. Продвинутые трансформации (Работа с колонками)
Здесь PySpark становится мощнее обычного SQL, так как позволяет использовать цепочки методов.
Создание и изменение колонок (withColumn)
# 1. Склеивание строк (Конкатенация)
df = df.withColumn("full_info", F.concat(F.col("code"), F.lit(" - "), F.col("location_name")))

# 2. Математика
df = df.withColumn("price_with_tax", F.col("price") * 1.2)

# 3. Условная логика (Аналог CASE WHEN в SQL)
df = df.withColumn("importance", 
    F.when(F.col("type") == "AIRPORT", "High")
     .when(F.col("type") == "CITY", "Medium")
     .otherwise("Low")
)

Работа с текстом и временем
# Изменение регистра
df = df.withColumn("upper_name", F.upper(F.col("location_name")))

# Вырезание части строки (например, первые 2 буквы кода)
df = df.withColumn("short_code", F.substring(F.col("code"), 1, 2))

# Работа с датами (текущее время)
df = df.withColumn("processed_at", F.current_timestamp())

3. Агрегация и Группировка (Широкие трансформации)
Это когда мы хотим сжать данные и посчитать статистику.
# Посчитать количество аэропортов в каждом городе
stats_df = df.groupBy("city").count()

# Посчитать среднюю цену и максимум по группам
stats_df = df.groupBy("city").agg(
    F.avg("price").alias("avg_price"),
    F.max("price").alias("max_price"),
    F.countDistinct("code").alias("unique_airports")
)

4. Работа с NULL (Очистка данных)
В данных из API часто бывают дыры. Инженер обязан их "залатать".
# Удалить строки, где код или имя — NULL
df = df.dropna(subset=["code", "location_name"])

# Заполнить все пустые значения в колонке "city" текстом "N/A"
df = df.fillna({"city": "N/A"})

# Coalesce: берет первое НЕ пустое значение из списка колонок
df = df.withColumn("final_name", F.coalesce(F.col("name"), F.col("iataCode"), F.lit("Unknown")))

5. Выполнение чистого SQL
Если тебе удобнее писать на SQL, PySpark позволяет делать и это!
# Сначала регистрируем таблицу во временной памяти Спарка
df.createOrReplaceTempView("my_airports")

# Теперь пишем обычный SQL запрос
sql_results = spark.sql("""
    SELECT 
        city, 
        UPPER(location_name) as name,
        COUNT(*) as cnt
    FROM my_airports
    WHERE type = 'AIRPORT'
    GROUP BY city, location_name
    HAVING cnt > 1
""")

Да, это называется объединением (Join) или вертикальным слиянием (Union). В Data Engineering это одна из самых важных тем.
В PySpark есть два способа «агрегировать» два разных набора данных (запроса):
1. Union (Вертикальное объединение)
Это когда ты берешь один список и приклеиваешь к нему снизу другой список.
 * Условие: У обоих запросов должны быть одинаковые колонки.
 * Пример: Ты скачал данные по Лондону, потом по Парижу, и хочешь один общий файл.
<!-- end list -->
# Запрос 1: Лондон
df_london = client.fetch_locations_paginated(keyword="London")
# Запрос 2: Париж
df_paris = client.fetch_locations_paginated(keyword="Paris")

# Объединяем их в один Spark DataFrame
df_combined = spark.createDataFrame(df_london).union(spark.createDataFrame(df_paris))

2. Join (Горизонтальное объединение)
Это классическая «агрегация» по ключу. Когда у тебя есть две таблицы и ты хочешь соединить их боками.
 * Пример: У тебя есть список аэропортов (с кодами IATA) и отдельный список с погодой или курсом валют для этих городов. Ты соединяешь их по колонке city или code.
<!-- end list -->
# Допустим, у нас есть вторая таблица с рейтингом безопасности городов
security_data = [("London", "High"), ("Paris", "Medium")]
security_df = spark.createDataFrame(security_data, ["city_name", "safety_level"])

# Соединяем нашу основную таблицу с таблицей безопасности
final_df = airports_df.join(
    security_df, 
    airports_df.city == security_df.city_name, 
    how="left" # Оставляем все аэропорты, даже если для них нет данных о безопасности
)

3. Агрегация с группировкой (Group By + Agg)
Если под «агрегацией двух запросов» ты имеешь в виду получение итоговой статистики из сырых данных, то это делается через groupBy.
Пример сложной трансформации для твоего кода:
Давай сделаем так: посчитаем количество аэропортов в каждом городе и добавим это число новой колонкой к каждой строке.
def transform_locations(spark: SparkSession, pdf: pd.DataFrame) -> DataFrame:
    df = spark.createDataFrame(pdf)
    
    # 1. Сначала чистим данные
    cleaned_df = df.select(
        F.col("name").alias("airport_name"),
        F.col("`address.cityName`").alias("city")
    ).filter(F.col("airport_name").isNotNull())

    # 2. Делаем агрегацию: считаем количество портов в каждом городе
    counts_df = cleaned_df.groupBy("city").count().withColumnRenamed("count", "total_airports_in_city")

    # 3. Соединяем (Join) обратно, чтобы у каждого аэропорта была инфо о "соседях"
    result_df = cleaned_df.join(counts_df, on="city", how="inner")
    
    return result_df

Короткая шпаргалка:
 * Нужно добавить строки снизу? Используй .union().
 * Нужно добавить колонки сбоку из другой таблицы? Используй .join().
 * Нужно посчитать сумму/среднее/количество? Используй .groupBy().agg().
