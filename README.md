# Amadeus Travel Data ETL Pipeline ✈️

Профессиональный ETL-пайплайн для сбора и обработки данных о местоположениях (аэропорты и города) с использованием **Amadeus API** и **PySpark**.

## 🛠 Технологический стек
* **Python 3.12**
* **PySpark 3.5.0** (обработка данных)
* **Pandas** (промежуточная обработка)
* **Requests** (работа с API)
* **Pytest** (модульное тестирование)
* **Excel/JSON** (выходные форматы)

## 🏗 Архитектура проекта
Проект построен по модульному принципу:
* `client.py` — Инкапсуляция логики API (OAuth 2.0, пагинация, обработка ошибок 429).
* `transform.py` — Чистые трансформации на PySpark.
* `test_etl.py` — Модульные тесты для проверки бизнес-логики.
* `main.py` — Главная точка входа (оркестрация процесса).
